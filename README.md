# North Peak Digital

A modern, responsive digital agency website built using React.js, TypeScript, and Tailwind CSS. The project focuses on delivering a clean user experience with reusable components, responsive layouts, and smooth navigation across all devices.

## 🚀 Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- Vite

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern and clean UI
- Reusable React components
- Smooth scrolling and interactive sections
- Optimized layout and performance
- Contact section with user-friendly interface
- Scalable project structure

## 📂 Project Structure

```
src/
 ├── components/
 ├── assets/
 ├── pages/
 ├── styles/
 ├── App.tsx
 └── main.tsx
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/pratyush1279/NorthPeakDigital.git
```

2. Navigate to the project directory

```bash
cd NorthPeakDigital
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open your browser

```
http://localhost:5173
```

## 🎯 Approach Taken

The project was developed using a component-based architecture to ensure code reusability and maintainability. Responsive layouts were implemented using Tailwind CSS, while TypeScript was used to improve type safety and scalability. The focus was on creating a professional digital agency website with clean design and optimized performance.

## 🤖 AI Usage

AI tools were used to assist with:
- UI inspiration and layout planning
- Component structure suggestions
- Code optimization
- Debugging and error resolution
- Content refinement

All generated code was manually reviewed, modified, and tested before being integrated into the project.
